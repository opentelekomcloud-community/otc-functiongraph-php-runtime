Bundled PHP Extensions
========================

Bundled PHP extensions can be used for **event** and **http** functions **build from scratch**.

If you want to use a different version of a runtime-included extension or additional extensions (e.g. GD extension,
you can do this by using container images.

For extensions bundled with a PHP runtime version see following pages:
